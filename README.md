
# Snakes and Ladders in C

This project implements a simulation of the classic Snakes and Ladders board game using the C programming language.

## Overview

The game simulates a single player moving across a 10x10 board based on random dice rolls. The player encounters snakes and ladders that affect their position and continues playing until reaching the final cell.

## Features

- Simulates random dice rolls
- Represents the game board using a 2D matrix
- Detects snakes and ladders using recursion
- Implements player movement and game rules
- Simulates gameplay until completion
- Tracks the total number of turns

## Technologies

- C Programming
- Structs
- 2D Arrays
- Recursion
- Random Number Generation

## How to Run

1. Make sure a C compiler (such as GCC) is installed.

2. Compile the program:

   ```bash
   gcc snakes_and_ladders.c -o game
   ```

3. Run the executable:

   ```bash
   ./game
   ```

## Output

The program displays:

- Dice rolls for each turn
- Player movement across the board
- Snake and ladder interactions
- Total number of turns required to finish the game
